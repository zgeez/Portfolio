# **App Name**: Ziad's Digital Portfolio

## Core Features:

- Personal Information: Display personal information (name, contact details, short bio).
- Project Showcase: Showcase projects with descriptions, images, and links.
- Experience Timeline: Display work experience with roles, responsibilities, and timelines.
- Education Details: List education with institutions and degrees.
- Skills Section: Highlight skills (programming languages, tools, frameworks).
- Social Links: Include links to LinkedIn and GitHub profiles in the header.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a clean and professional feel.
- Background color: Very light blue (#F0F8FF) for a soft and unobtrusive backdrop.
- Accent color: Darker blue (#0077B6) to highlight important information and links.
- Body and headline font: 'Inter', a sans-serif font for a clean, modern and easily readable look.
- Use simple, consistent icons for navigation and to represent skills and technologies.
- Implement a clean, one-page layout with clear sections for easy navigation, following the reference website's design.
- Subtle animations, such as fading effects on scroll, to add visual interest without being distracting.
