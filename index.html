Debug log

Measured, then explained

Short postmortems: symptom, measurement, root cause, fix, result. Each links to the full write-up.

0x01 · STM32 USB latency floor

20 ms → 0.22 ms

  1. SymptomEvery request took almost exactly 20 ms.
  2. ObservationTransfers were exact multiples of it. Throughput limits don’t quantize; timeouts do.
  3. Root causetasks_notify_control() was never called from the CDC callbacks; the task woke only on its 10 ms timeout.
  4. FixNotify from RX and TX-complete callbacks, inside CubeMX user-code regions.
  5. Result0.221 ms median RTT · 86× capture throughput
Full postmortem →: STM32 USB latency floor

0x02 · Analog/digital synchronization

−120 ns, explained

  1. GoalCompare a 1 MS/s analog path and a 9.882 MS/s logic path on one axis.
  2. FixTIM1’s trigger output releases a slaved TIM2: one hardware start, not two software commands.
  3. MeasurementResidual skew of −120 ns between the paths; no jitter resolvable above sampling quantization.
  4. Root causeMatches the ADC’s 143 ns sample-and-hold aperture. A shared start is not a shared sampling instant.
  5. ResultSkew traced to a mechanism, not left as a residual.
Full postmortem →: Analog/digital synchronization

0x03 · EEG label and data quality

70.0% → 82.9%

  1. SymptomInitial 5-run model: 70.0% block accuracy, 55.5 generalization score.
  2. Root causeMisaligned task markers silently poison labels; blink and motion transients swamp short windows.
  3. FixMarkers written by the task launcher and aligned to the sample stream; artifact gating before features; complete 8-channel runs.
  4. Result82.9% block accuracy and 78.2 generalization on 10 runs, from data hygiene rather than model complexity.
