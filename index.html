Debug log

Measured, then explained

Problem, root cause, result. Open a postmortem for the measurements and complete debugging process.

0x01 · STM32 USB latency floor

20 ms → 0.22 ms

Problem
Every request took almost exactly 20 ms.
Root cause
tasks_notify_control() was never called from the CDC callbacks; the task woke only on its 10 ms timeout.
Result
0.221 ms median RTT · 86× capture throughput
Full postmortem →: STM32 USB latency floor

0x02 · Analog/digital synchronization

−120 ns, explained

Problem
Compare a 1 MS/s analog path and a 9.882 MS/s logic path on one axis.
Root cause
Matches the ADC’s 143 ns sample-and-hold aperture. A shared start is not a shared sampling instant.
Result
Skew traced to a mechanism, not left as a residual.
Full postmortem →: Analog/digital synchronization

0x03 · EEG label and data quality

70.0% → 82.9%

Problem
Initial 5-run model: 70.0% block accuracy, 55.5 generalization score.
Root cause
Misaligned task markers silently poison labels; blink and motion transients swamp short windows.
Result
82.9% block accuracy and 78.2 generalization on 10 runs, from data hygiene rather than model complexity.
Full postmortem →: EEG label and data quality
