L0 / Product

Can a low-cost rig separate rest from task?

Can a locally processed, low-cost 8-channel EEG rig reliably separate rest from cognitive task?

Sustained engagement is hard to measure in a classroom: the usual feedback is delayed, observational, and non-adaptive. Answering the narrower engineering question meant building the entire chain: analog front end, embedded firmware, acquisition software, labeled data collection, a supervised model, and a teacher-facing display.

My role was software lead: the MATLAB acquisition and processing pipeline, ESP32-S3/ADS1299 firmware bring-up, the model training workflow, and dashboard integration.

Scope

An engineering proof-of-concept. It does not diagnose or treat any condition; its output is a Rest-vs-Task classification used as a cautious proxy for task engagement, not a measure of attention or ability.

L2 / Acquisition

ADS1299, SPI firmware and the montage

Rather than use the stock DSP motherboard path, the TI ADS1299EEG-FE was brought up against an ESP32-S3 acting as SPI master: the MCU configures the channel registers, starts continuous conversion, reads each 27-byte frame on the DRDY interrupt, and forwards framed binary packets over USB serial at 250 Hz.

SPI bring-up

  • Register configuration for all 8 channels
  • Gain, reference buffer, and bias-drive setup
  • RDATAC continuous-read mode
  • Clock/timing validation with logic analysis

Streaming

  • DRDY-triggered frame capture
  • Status word + 8 × 24-bit signed samples
  • Framed binary packets over USB serial
  • Drop counting for stream integrity

The prototype started as a single-channel setup with very limited spatial coverage. The final montage spans frontal, central, and parietal sites: enough coverage to separate executive-task activity from rest without making setup impractical for repeated sessions.

  • F3 / Fz / F4: frontal and executive-task-related activity
  • C3 / Cz / C4: central and sensorimotor rhythm activity
  • P3 / P4: parietal task-state information for the classifier
  • Fpz drives bias to reduce common-mode noise; TP8 references away from measurement sites

Labels come from the task launcher

Every recording alternates rest and task blocks, with markers written by the task launcher itself (Rest = 0, Task = 1). Marker alignment turned out to be one of the highest-leverage details in the project: misaligned blocks silently poison the training set.

Why it mattered

The jump from 70.0% to 82.9% block accuracy came from complete 8-channel recordings and stricter marker/artifact hygiene rather than from model complexity.

L4 / Classification

Random Forest over bandpower windows

A Random Forest over spectral features from 5-second windows with a 2.5-second step. Each window contributes Welch-PSD-derived bandpower features across all eight channels; artifact and outlier rejection runs before inference. The model outputs P(Task), and a tuned threshold converts it into a Rest-vs-Task decision. Block accuracy aggregates window predictions across a full block.

Privacy, safety & scope

Local-first, no diagnostic claims

Local-first processing

Acquisition, markers, inference, and display all run locally. No cloud processing is required for the core workflow, which limits exposure of sensitive EEG and session data.

No diagnostic claims

The system does not diagnose or treat ADHD or any other condition. Its output is an engineering classification result, not a medical conclusion.

Data minimization

Only the data needed for testing, training, and validation is retained, using anonymous subject and session labels.

Supervised use only

Used under supervision within senior-design constraints. Any classroom or child-facing deployment would require consent procedures and institutional review.

Limitations & future work

Next

  • Broader dataset: more subjects, to test cross-subject generalization.
  • Live inference: integrate the latest exported model directly into the dashboard path.
  • Artifact handling: stronger rejection for blink and motion transients.
  • Setup ergonomics: better cap comfort, shorter time-to-first-signal.
  • Validation: supervised, IRB-style usability testing before any classroom use.
