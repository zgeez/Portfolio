Overview

A digit that moves instead of glowing

A tactile, daylight-readable digit that spends power only when it changes.

The LED digit used for comparison draws ≈250 mA. Here each segment is a PLA bar with an N35 magnet; a 400-turn screw-core coil repels or attracts it for 25 ms, then consumes nothing until the next change.

The build covers precision electromechanics, energy-aware firmware, and rapid-prototyped mechanics in one single-digit module.

Mechanics

Rails, magnets and a screw for a core

  • Each segment is a PLA bar carrying an N35 magnet, riding a 3D-printed low-friction rail
  • An M3 screw is the coil’s low-cost steel core
  • The PLA rail keeps skew under 0.1 mm, so a 1 A pulse yields 7 mm of travel
  • Bistable: a bar stays where it was pushed with no current applied

Pain point

Rail printing demanded ±0.02 mm tolerance.

Electronics

Coils and H-bridges

  • Hand-wound 400-turn coils, hot-swappable
  • Seven TB6612 H-bridge channels, driven directly from 14 GPIOs
  • Polarity of the pulse decides whether the bar is pushed or pulled
  • Next revision: multiplex through a 74HC595 to free I/O

Firmware

Pulse only what changes

The segment font lives in flash. Each update, the loop XORs the desired mask with the current one and energizes only the bars that changed, for under 25 ms each. Nothing is driven to hold a state.

Debug note

The first coils overheated. Gating actuation on the XOR diff, so unchanged bars are never pulsed, fixed it.

Energy

Where the 100× comes from

Power is spent only during pulses, so the average is set by pulse current, pulse width and how many pulses happen per minute. The budget below assumes 8 pulses a minute, a conservative figure for a display that changes once a minute.

Reflection

What worked, and what’s next

Worked

Repeatable motion, no hold current, and hot-swap coils proved the mechanical concept.

Pain points

Coils overheated until XOR gating was added; rail printing demanded ±0.02 mm tolerance.

Roadmap

Shift-register I/O, an air-core/keeper redesign to halve pulse current, BLE OTA updates, and a 4-digit backplane PCB.

Built with

Stack

Fusion 360, KiCad, STM32CubeIDE, and C firmware.
