Overview

Community security, in real time

A cross-platform Flutter app for Android and iOS that lets businesses share security incidents, receive real-time alerts, and strengthen collective security through collaborative reporting and geo-fenced notifications.

Powered by Firebase, it lets businesses report incidents instantly, receive alerts for nearby events, and access community-driven security information to help prevent theft.

Features

What it does

Real-time alerts

  • Live feed of nearby incidents
  • Distance-based filtering
  • Geo-fenced push notifications
  • Severity color coding

Incident reporting

  • Multi-image capture and upload
  • Automatic location tagging
  • Incident categories
  • Real-time database sync

Map integration

  • Google Maps with custom markers
  • Incident clustering by location
  • Business location verification
  • Navigation and directions

Subscriptions

  • Stripe payments
  • 7-day free trial
  • Feature-gated access
  • Subscription management portal
