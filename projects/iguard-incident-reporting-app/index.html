iGuard - Community Incident Reporting App

A cross-platform mobile app built with Flutter for Android and iOS that empowers businesses to share security incidents, receive real-time alerts, and enhance collective security through collaborative information sharing and geo-fenced notifications.

Project Overview

iGuard addresses the critical need for real-time security information sharing among businesses. Built with Flutter for cross-platform deployment on Android and iOS and powered by Firebase, the app enables businesses to report incidents instantly, receive geo-fenced alerts, and access community-driven security intelligence to prevent theft and enhance safety measures.

Real-time Alert System

  • Live feed of nearby incidents
  • Distance-based filtering
  • Push notifications with geo-fencing
  • Severity-based color coding

Incident Reporting

  • Multi-image capture and upload
  • Auto-location tagging
  • Incident categorization
  • Real-time database sync

Map Integration

  • Google Maps with custom markers
  • Incident clustering by location
  • Business location verification
  • Navigation and directions

Subscription System

  • Stripe payment integration
  • 7-day free trial
  • Feature-gated access control
  • Subscription management portal

Technical Challenges & Solutions

  • Real-time Data Sync: Implemented Firestore listeners with Flutter streams for instant incident updates across all connected devices.
  • Geo-fencing Performance: Optimized location-based queries using GeoPoint and cloud functions to minimize battery drain while maintaining accuracy.
  • Payment Integration: Built secure Stripe integration with webhook handling via Cloud Functions for reliable subscription management.
  • Image Upload Optimization: Implemented progressive image compression and Firebase Storage rules for efficient multi-image uploads.

Impact & Future Development

The app demonstrates expertise in modern mobile development practices, real-time systems, and payment processing. Future enhancements include machine learning for incident pattern recognition, advanced analytics dashboards, and integration with existing security systems.
