IoT Device Automation System

A modular, battery‑friendly platform that retrofits legacy machinery with AWS‑connected intelligence—delivering instant, scheduled, or sensor‑driven automation through a Flutter mobile app.

Overview

The project delivers drop‑in IoT nodes based on ESP32 (ESP‑IDF) that bolt onto existing industrial panels without disrupting production. Each node auto‑registers with AWS IoT Core, streams telemetry, and executes Lambda‑backed automation rules.

Key Capabilities

  • Hot‑swappable sensor decks: SPI/I²C mezzanines slot into a common backplane, cutting deployment time from hours to minutes.
  • Ultra‑low power firmware: Multi‑mode deep sleep with RTC wakeups and Brownout watchdog extends battery life ×3 versus baseline.
  • Cloudless fallback: MQTT‑mesh gossip maintains local rules during WAN outages.
  • Flutter companion app: Real‑time dashboards, on‑device OTA upgrades, and drag‑and‑drop workflow builder.

System Architecture

The serverless backend (Lambda + API Gateway) offloads stateful logic to DynamoDB, while time‑critical commands travel via reserved MQTT topics for <200 ms round‑trip.

Mobile Experience

A reactive UI built with Riverpod streams live telemetry over MQTT and lets users compose automation chains visually—mirroring Node-RED’s UX but tuned for mobile ergonomics.

Critical Reflection

Challenges

  • Negotiating stable SPI & I²C timing across hot‑swapped daughter‑cards.
  • Balancing TLS handshake overhead with aggressive deep‑sleep budgets.
  • Mitigating cold‑start Lambda latency on telemetry write spikes.

Solutions & Lessons

  • Implemented board‑level EEPROM meta‑data to auto‑tune bus timing.
  • Cached MQTT session params in RTC fast‑mem, trimming reconnect approximately 80 ms.
  • Switched DynamoDB tables to On‑Demand mode with adaptive capacity and partition‑key sharding.

Next Steps

Exploring Matter‑over‑Thread compatibility and moving critical edge‑compute pieces onto the ESP’s dual‑core RTOS to reduce cloud dependency.

Tech Stack

  • Firmware: ESP‑IDF | FreeRTOS | C/C++17
  • Cloud: AWS IoT Core | Lambda (Node.js) | API Gateway | DynamoDB | S3 | CodePipeline
  • Mobile: Flutter | Riverpod | AWS Amplify
