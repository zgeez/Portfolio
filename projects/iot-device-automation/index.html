Overview

Retrofitting machines with cloud automation

A modular, battery-friendly platform that retrofits legacy machinery with AWS-connected control: instant, scheduled, or sensor-driven automation from a Flutter mobile app.

Drop-in ESP32 nodes (ESP-IDF) bolt onto existing industrial panels without disrupting production. Each node auto-registers with AWS IoT Core, streams telemetry, and executes Lambda-backed automation rules.

  • Hot-swappable sensor decks: SPI/I²C mezzanines on a common backplane cut deployment from hours to minutes.
  • Low-power firmware: multi-mode deep sleep with RTC wakeups and a brownout watchdog.
  • Cloudless fallback: MQTT mesh gossip keeps local rules running during WAN outages.
  • Companion app: real-time dashboards, OTA upgrades, and a drag-and-drop workflow builder.

Device ↔ AWS ↔ app

Architecture

The serverless backend (Lambda + API Gateway) keeps state in DynamoDB, while time-critical commands travel on reserved MQTT topics for a sub-200 ms round trip.

Implementation

Firmware & power management

  • ESP-IDF on FreeRTOS, C/C++17
  • Multi-mode deep sleep with RTC wakeups extends battery life ×3 versus baseline
  • Brownout watchdog
  • MQTT session parameters cached in RTC fast memory, trimming reconnect by about 80 ms
  • Board-level EEPROM metadata auto-tunes bus timing for hot-swapped daughter cards

Power modes

The app exposes three modes per device: Real-Time (fastest response, highest consumption), Power Saving (balanced), and Super Power Saving (lowest consumption, slower response).

Mobile app

Flutter companion

A reactive UI built with Riverpod streams live telemetry over MQTT and lets users compose automation chains visually. Devices are provisioned with ESP SmartConfig.
