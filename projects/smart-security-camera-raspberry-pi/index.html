Overview

Edge AI on a Raspberry Pi 5

A complete edge-AI security system that combines PIR sensor triggering with YOLOv11n object detection, optimized for Raspberry Pi 5 to reach real-time person detection, with event recording and a web dashboard for monitoring and control.

Real-time performance comes from an INT8-quantized YOLOv11n on the NCNN backend, motion gating so inference runs only when something moves, and a multi-threaded architecture that keeps capture, inference and web serving out of each other’s way.

Optimizations

From 3 to 30 FPS

  • Motion gating: the PIR sensor triggers YOLO only when motion is detected, reducing CPU usage by 70% during idle periods.
  • INT8 quantization: inference time from 330 ms to 33 ms while keeping 95% accuracy on person detection.
  • Multi-threading: video capture, inference and web serving in independent threads.
  • Asynchronous processing: background video conversion never blocks the real-time detection pipeline.
